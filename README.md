# 포커 어시스턴트 (Poker Assistant)

텍사스 홀덤 플레이어를 위한 웹 기반 도우미입니다.
승률 계산, 핸드 기록·분석, 프리플랍 레인지 관리를 한곳에서 할 수 있도록 하는 것이 목표입니다.
데스크톱과 모바일 모두에서 동일하게 쓸 수 있는 반응형 웹앱으로 만듭니다.

> 현재 상태: **3단계 완료** (프로젝트 기반, 포커 엔진, 승률 계산기, 레인지 차트). 아래 기능은 순차적으로 개발 중입니다.

---

## 주요 기능

### 1. 승률 / 에퀴티 계산기
- 내 핸드(2장), 보드(0~5장), 상대 수(1~9명)를 입력하면 승률·무승부율·에퀴티를 계산
- 상대 핸드를 랜덤, 특정 카드, 또는 저장한 **레인지**로 지정
- 상대 핸드를 모두 알 때: 다음 카드 기준 아웃츠(역전 카드)·위험 카드와 그 확률 표시
- 리버까지 내가 완성할 족보(플러시, 스트레이트 등)의 확률 분포 표시
- 팟 오즈 계산: 팟 크기와 콜 금액을 넣으면 콜이 이득인지(+EV) 판단
- 계산 방식
  - 남은 경우의 수가 적으면 **완전 열거(exact enumeration)**
  - 많으면 **몬테카를로 시뮬레이션**으로 근사
  - 계산은 Web Worker에서 실행해 UI가 멈추지 않게 함

### 2. 핸드 기록 / 분석
- 플레이한 핸드를 스트리트별(프리플랍·플랍·턴·리버)로 기록
  - 포지션, 스택, 홀카드, 보드, 각 스트리트의 액션(폴드/체크/콜/벳/레이즈), 결과
- 세션 단위 관리: 날짜, 장소/사이트, 블라인드, 바이인·캐시아웃
- 통계 대시보드
  - 누적 손익 그래프, 세션별 손익
  - VPIP, PFR, 3Bet%, 포지션별 승률 등
- 기록한 핸드를 다시 재생(리플레이)하며 복기
- 데이터 내보내기/가져오기 (JSON)

### 3. 프리플랍 레인지 차트
- 169개 스타팅 핸드를 13×13 그리드로 표시 (페어 / 수딧 / 오프수딧)
- 포지션(UTG ~ BB)·상황(오픈, 콜, 3Bet 등)별로 레인지를 만들고 편집
- 클릭·드래그로 칸을 칠해 액션 지정, 레인지 비율(%)과 콤보 수 자동 계산
- 기본 제공 레인지(6-max 100BB 포지션별 오픈, 참고용) + 사용자 정의 레인지 저장
- 표준 표기(`QQ+, ATs+, A5s-A2s, KQo`)로 보기·입력
- 만든 레인지를 에퀴티 계산기의 상대 레인지로 바로 사용

### 4. 베팅 사이즈 추천
내 핸드·보드·팟·스택·상대 레인지를 입력하면 **몇 BB를 베팅하면 좋은지** 추천합니다.

- **프리플랍**: 포지션, 앞선 액션(림프/오픈/3Bet), 유효 스택 깊이에 따른 표준 오픈·3Bet·4Bet 사이즈를 BB 단위로 제시
- **포스트플랍**: 후보 사이즈별 기대값(EV)을 비교해 가장 높은 사이즈 추천
  - 후보: 체크, 25% / 33% / 50% / 75% / 100% / 150% 팟, 올인
  - `EV(베팅) = 폴드율 × 팟 + (1 − 폴드율) × (콜당했을 때의 EV)`
  - 상대의 폴드율은 상대 레인지 안에서 각 콤보가 계속할 만한지(에퀴티 vs 팟 오즈)로 추정하고, MDF(최소 방어 빈도)로 보정
- **상황 보정**
  - 보드 텍스처: 드라이(작게) / 웻·드로우 많음(크게)
  - SPR(스택 대 팟 비율): 낮으면 올인까지 염두에 둔 사이즈
  - 내 핸드 분류: 강한 밸류 / 얇은 밸류 / 드로우(세미블러프) / 순수 블러프 / 쇼다운 밸류(체크 권장)
- **결과 표시**: `추천: 6.5 BB (팟의 66%)`와 함께 후보별 EV 비교표와 추천 근거를 보여줌

> ⚠️ 이 추천은 단순화한 모델로 낸 **추정치**이며, GTO 솔버의 정답이 아닙니다. 공부와 복기용으로 쓰는 것을 권장합니다.
> 대부분의 온라인 포커 사이트는 **게임 중 실시간 보조 도구(RTA) 사용을 금지**하므로, 실전 온라인 플레이 중에는 사용하지 마세요.

## 기술 스택

| 영역 | 선택 |
| --- | --- |
| 프레임워크 | React + TypeScript |
| 빌드 도구 | Vite |
| 스타일 | Tailwind CSS |
| 상태 관리 | Zustand |
| 로컬 저장소 | 레인지 등 작은 설정: localStorage / 핸드 기록: IndexedDB (Dexie.js) |
| 차트 | Recharts |
| 테스트 | Vitest + React Testing Library |
| 무거운 계산 | Web Worker |

서버 없이 브라우저만으로 동작합니다. 모든 데이터는 사용자 기기에 저장됩니다.

## 프로젝트 구조 (예정)

```
src/
├── core/                # UI와 무관한 포커 로직 (순수 TypeScript)
│   ├── cards.ts         #   카드·덱 표현
│   ├── evaluator.ts     #   7장 핸드 족보 판정
│   ├── equity.ts        #   에퀴티 계산 (열거 / 몬테카를로)
│   ├── range.ts         #   레인지 파싱·콤보 계산
│   ├── board.ts         #   보드 텍스처 분석 (드라이/웻, 드로우 여부)
│   └── sizing.ts        #   베팅 사이즈 후보별 EV 계산·추천
├── workers/             # Web Worker (에퀴티 계산)
├── features/
│   ├── equity/          # 승률 계산기 화면
│   ├── hands/           # 핸드 기록·분석 화면
│   ├── ranges/          # 레인지 차트 화면
│   └── sizing/          # 베팅 사이즈 추천 화면
├── components/          # 공용 UI (카드 선택기, 그리드 등)
├── db/                  # IndexedDB 스키마와 접근 함수
└── App.tsx
```

`core/`는 React에 의존하지 않도록 분리해서 단위 테스트를 쉽게 합니다.

## 시작하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev         # 개발 서버 실행 (http://localhost:5173)
npm run test        # 테스트 1회 실행
npm run test:watch  # 테스트 감시 모드
npm run lint        # 린트 (oxlint)
npm run build       # 프로덕션 빌드
```

## 용어 정리

| 용어 | 뜻 |
| --- | --- |
| 에퀴티 (Equity) | 현재 상황에서 팟을 가져갈 기대 비율 |
| 아웃츠 (Outs) | 내 핸드를 이기는 핸드로 만들어 주는 남은 카드 |
| 팟 오즈 (Pot Odds) | 콜 금액 ÷ (팟 + 콜 금액). 에퀴티가 이보다 크면 콜이 이득 |
| VPIP | 프리플랍에 자발적으로 돈을 넣은 비율 |
| PFR | 프리플랍에 레이즈한 비율 |
| 레인지 (Range) | 특정 상황에서 플레이어가 가질 수 있는 핸드의 집합 |
| BB (Big Blind) | 빅 블라인드 금액. 베팅 크기를 블라인드와 상관없이 비교하기 위한 단위 |
| EV (Expected Value) | 어떤 선택을 했을 때 평균적으로 얻는 칩의 양 |
| SPR | 유효 스택 ÷ 팟. 낮을수록 올인에 가까운 상황 |
| MDF | 상대의 블러프가 이득을 보지 못하게 하려면 최소한 계속해야 하는 비율 = 팟 ÷ (팟 + 베팅) |
| 폴드 에퀴티 | 내 베팅에 상대가 폴드해서 얻는 기대값 |
